# Equation Solver

A React web app for solving linear, quadratic, cubic, and quartic equations.

## Features

- Linear equation solver: `ax + b = c`
- Quadratic equation solver: `ax² + bx + c = 0`
- Cubic and quartic polynomial solvers
- Supports complex roots where needed
- A card-based homepage with a separate solver page for each equation type

## Run it locally

1. Clone or download the project.
2. Open a terminal in the project folder.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local address shown in the terminal, usually `http://localhost:5173`.

## Built with

- React
